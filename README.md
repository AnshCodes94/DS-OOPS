## 📚 Topics Covered

* **Core Java & Basics**
  ![Core Java](https://img.shields.io/badge/Core_Java-Classes_%7C_Objects_%7C_Constructors_%7C_Keywords-orange?style=flat-square)
  * Classes, Objects, Constructors, `this` and `super` keywords, `static` members, and `final` keyword.

* **OOP Pillars**
  ![OOP Pillars](https://img.shields.io/badge/OOP_Pillars-Abstraction_%7C_Encapsulation_%7C_Inheritance_%7C_Polymorphism-blue?style=flat-square)
  * Abstraction, Encapsulation, Inheritance (Single, Multilevel, Hierarchical), and Polymorphism (Overloading & Overriding).

* **Arrays & String Processing**
  ![Arrays & Strings](https://img.shields.io/badge/Data_Structures-1D/2D_Arrays_%7C_StringBuilder-green?style=flat-square)
  * 1D Arrays, 2D Arrays (Matrices), String manipulations, and performance optimization using `StringBuilder`.

* **Collections Framework & Data Structures**
  ![Collections](https://img.shields.io/badge/Collections-ArrayList_%7C_LinkedList_%7C_Set-purple?style=flat-square)
  * Lists (`ArrayList`, `LinkedList`) and Sets (`LinkedHashSet`, `TreeSet`) with underlying memory layout and performance trade-offs.

* **Exception Handling**
  ![Exception Handling](https://img.shields.io/badge/Errors-Exception_Handling-yellow?style=flat-square)
  * `try-catch` blocks, `finally`, custom exceptions, `throw`, and `throws`.
